## Part E — Inspect the SQL generated by Eloquent

1. Open `app/Http/Controllers/BookQueryController.php`.
2. Temporarily replace the Eloquent block with:

```php
$eloquentQuery = Book::query()
    ->when($search, function ($query) use ($search) {
        $query->where('title', 'like', '%' . $search . '%');
    })
    ->when($lowStock, function ($query) use ($stockLimit) {
        $query->where('stock', '<', $stockLimit);
    })
    ->orderBy('amount')
    ->limit(20);

dd($eloquentQuery->toSql(), $eloquentQuery->getBindings());
```

3. Reload the page. Take **Screenshot 4** of the output.
4. Write your answers from what you see:
   - **SQL template:** a `select * from books where ...` statement with `?` placeholders, ending in `order by amount asc limit 20`.
   - **What the bindings represent:** the real values that replace each `?`, such as `%dig%` and the stock number. They are sent to the database separately from the SQL, which protects against SQL injection.
5. Remove the `dd(...)` and restore the original Eloquent query. The page stops at `dd()` otherwise, and `dd()` must never stay in a deployed application.

## Part I — Troubleshooting

| Problem | What to check |
|---|---|
| Class Book not found | Confirm `app/Models/Book.php` exists and `App\Models\Book` is imported |
| View not found | Check `resources/views/pages/book-query-comparison.blade.php` and the view name `pages.book-query-comparison` |
| Route not found | Check `routes/web.php` and run `php artisan route:list` |
| Database connection error | Check the DB settings in `.env`. Run `php artisan config:clear` |
| Both columns empty | Confirm the books table has records (`php artisan db:seed --class=BookSeeder`) and that your filters match existing data |
| Results differ | Check both query chains use the same conditions, ordering and limit |
| Page stops at a dump | Remove the temporary `dd()` after inspecting the SQL and bindings |

The worksheet ends with: if something is not working, figure it out and document how you solved it. Keep a short note for any problem you hit.
